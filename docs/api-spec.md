# Memo API 設計書

## 1. 共通仕様

### エラーレスポンス

すべてのAPIでエラーレスポンスは以下の形式に統一する。

```json
{
  "error": {
    "code": "",
    "message": ""
  }
}
```

---

## 2. GET /health

### HTTPメソッド

GET

### URL

`/health`

### 目的

サーバーが稼働していることを確認する。

### リクエスト例

```http
GET /health
```

### 正常レスポンス例

ステータスコード：200 OK

```json
{
  "status": "ok"
}
```

### エラーレスポンス例

ステータスコード：500 Internal Server Error

```json
{
  "error": {
    "code": "INTERNAL_SERVER_ERROR",
    "message": "アプリケーションサーバー内部にてエラーが発生しました"
  }
}
```

### HTTPメソッドを選んだ理由

/healthからデータを取得(GET)することにより、サーバーが稼働しているかどうか確認できるため

### ステータスコードを選んだ理由

正常時：リクエストが正常に処理され、サーバーの稼働状態を正常に返せたため
エラー時：サーバー側で予期しないエラーが発生し、リクエストを正常に処理できないため

---

## 3. GET /memos

### HTTPメソッド

GET

### URL

`/memos`

### 目的

メモの一覧をJSONで返す。

### リクエスト例

```http
GET /memos
```

### 正常レスポンス例

ステータスコード：200 OK

メモが１件以上ある場合：
```json
[
 {
   "id":"001",
   "title": "メモ１",
   "memoText":"サンプルメモ１"
 },
 {
   "id":"002",
   "title": "メモ２",
   "memoText":"サンプルメモ２"
 } 
]
```
メモが０件の場合
```json
[]
```


### エラーレスポンス例

ステータスコード：500 Internal Server Error

```json
{
  "error": {
    "code": "INTERNAL_SERVER_ERROR",
    "message": "アプリケーションサーバー内部にてエラーが発生しました"
  }
}
```

### HTTPメソッドを選んだ理由

/memosからメモの一覧をすべて取得するため。

### ステータスコードを選んだ理由

正常時：リクエストが正常に処理され、メモ一覧を正常に返せたため
エラー時：サーバー側で予期しないエラーが発生し、リクエストを正常に処理できないため

---

## 4. GET /memos/:id

### HTTPメソッド

GET

### URL

`/memos/:id`

### 目的

指定IDのメモをJSONで返す。

### リクエスト例

```http
GET /memos/001
```

### 正常レスポンス例

ステータスコード：200

```json
{
   "id":"001",
   "title": "メモ１",
   "memoText":"サンプルメモ１"
}
```

### エラーレスポンス例

ステータスコード：404 Not Found

```json
{
  "error": {
    "code": "MEMO_NOT_FOUND",
    "message": "指定したメモが見つかりません"
  }
}
```

### HTTPメソッドを選んだ理由

/memos/:idから任意のメモを取得するため。

### ステータスコードを選んだ理由

正常時：指定したIDのメモが/memosに存在しリクエストが正常に処理され、任意のメモを正常に返せたため
エラー時：指定したIDのメモが/memosに存在せず、指定したメモを返すことができなかったため

---

## 5. POST /memos

### HTTPメソッド

POST

### URL

`/memos`

### 目的

タイトルと本文を受け取り、新しいメモを作成する

### リクエスト例

```http
POST /memos
Content-Type: application/json
```

```json
{
   "title": "メモ３",
   "memoText":"サンプルメモ３"
}
```

### 正常レスポンス例

ステータスコード：201 Created

```json
{
   "id":"003",
   "title": "メモ３",
   "memoText":"サンプルメモ３"
}
```

### エラーレスポンス例

ステータスコード：400 Bad Request

メモのタイトルがない場合：
```json
{
  "error": {
    "code": "MEMO_NOT_TITLE",
    "message": "タイトルを入力してください"
  }
}
```

メモの本文がない場合：
```json
{
  "error": {
    "code": "MEMO_NOT_TEXT",
    "message": "本文を入力してください"
  }
}
```

メモのタイトルが空白の場合：
```json
{
  "error": {
    "code": "MEMO_NOT_TITLE",
    "message": "タイトルを入力してください"
  }
}
```

メモのタイトルが４０文字を超えた場合：
```json
{
  "error": {
    "code": "MEMO_TEXT_40WORD_OVER",
    "message": "タイトルは４０文字以内にしてください"
  }
}
```


メモの本文が２５０文字を超えた場合：
```json
{
  "error": {
    "code": "MEMO_TITLE_250WORD_OVER",
    "message": "メモ本文は２５０文字以内にしてください"
  }
}
```

### HTTPメソッドを選んだ理由

/memosに新規のメモを追加したいため

### ステータスコードを選んだ理由

正常時：追加するメモが/memoに追加され、正常にリソースが作成されたため
エラー時：追加するメモのリクエストに不正な値があったため

## 6. PATCH /memos/:id

### HTTPメソッド

PATCH

### URL

`/memos/:id`

### 目的

指定されたメモのタイトルまたは本文を更新する

### リクエスト例

```http
PATCH /memos/001
```

```json
{
  "title": "メモ１_更新済み",
  "memoText": "サンプルメモ１_更新済み"
}
```

### 正常レスポンス例

ステータスコード：200 OK

```json
{
  "id": "001",
  "title": "メモ１_更新済み",
  "memoText": "サンプルメモ１_更新済み"
}
```

### エラーレスポンス例


ステータスコード：400 Bad Request

メモのタイトルおよび本文がない場合：
```json
{
  "error": {
    "code": "MEMO_UPDATE_DATA_REQUIRED",
    "message": "タイトルまたは本文を入力してください"
  }
}
```


メモのタイトルが４０文字を超えた場合：
```json
{
  "error": {
    "code": "MEMO_TITLE_40WORD_OVER",
    "message": "タイトルは４０文字以内にしてください"
  }
}
```

メモの本文が２５０文字を超えた場合：
```json
{
  "error": {
    "code": "MEMO_TEXT_250WORD_OVER",
    "message": "メモ本文は２５０文字以内にしてください"
  }
}
```

ステータスコード：404 Not Found

```json
{
  "error": {
    "code": "MEMO_NOT_FOUND",
    "message": "指定したメモが見つかりません"
  }
}
```

### HTTPメソッドを選んだ理由

指定したメモのタイトルまたは本文を更新するため

### ステータスコードを選んだ理由

正常時：指定したメモが存在し、タイトルまたは本文の更新が正常に完了したため
エラー(400)時：リクエストに不正な値があり、メモの更新ができなかったため
エラー(404)時：指定したIDのメモが存在せず、対象のリソースが存在しなかったため

## 7. DELETE /memos/:id

### HTTPメソッド

DELETE

### URL

`/memos/:id`

### 目的

指定されたメモを削除する

### リクエスト例

```http
DELETE /memos/001
```

### 正常レスポンス例

ステータスコード：204 No Content


### エラーレスポンス例

ステータスコード：404 Not Found

```json
{
  "error": {
    "code": "MEMO_NOT_FOUND",
    "message": "指定したメモが見つかりません"
  }
}
```

### HTTPメソッドを選んだ理由

指定したIDのメモを/memos内から削除するため

### ステータスコードを選んだ理由

正常時：指定したメモが存在し、メモの削除が正常に完了したため。また、返却するデータがないため
エラー時：指定したIDのメモが存在せず、対象のリソースを削除できなかったため
